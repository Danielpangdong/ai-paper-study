# Sources — Harness Handbook

Primary evidence (checked 2026-07-17, English first-party sources):

1. Wang et al., [Harness Handbook: Making Evolving Agent Harnesses Readable, Navigable, and Editable](https://arxiv.org/abs/2607.13285), arXiv:2607.13285v1, submitted 2026-07-14. Metadata, abstract, version, project link.
2. [Paper HTML v1](https://arxiv.org/html/2607.13285v1) and [PDF](https://arxiv.org/pdf/2607.13285). Method §3; evaluation §4; Table 1–4; Appendix C. All report numerical claims trace to this version.
3. [Official project page](https://ruhan-wang.github.io/Harness-Handbook/). Author affiliations, readable explanation, interactive demo.
4. [Official GitHub: Ruhan-Wang/Harness_Handbook](https://github.com/Ruhan-Wang/Harness_Handbook). Public source, command examples, Chinese narration and HTML generation options, planner-helper implementation.

Independent / related baseline context:

5. Jimenez et al., [SWE-bench: Can Language Models Resolve Real-World GitHub Issues?](https://arxiv.org/abs/2310.06770), ICLR 2024. Independent benchmark context: final issue resolution versus Harness Handbook's edit-site localization and plan quality.
6. [SWE-bench official project page](https://www.swebench.com/original.html). Benchmark construction: 2,294 instances from 12 Python repositories and fail-to-pass test evaluation.

Evidence note: Harness Handbook's numbers are author-run results. This automation inspected source material and built a report, but did not rerun the planner, build the handbook, execute patches, or independently reproduce the evaluation.
