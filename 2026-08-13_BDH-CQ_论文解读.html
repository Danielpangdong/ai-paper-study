一句话看懂

Pathway 团队用一个只有 1.5 亿参数的模型，在被视作"类人推理试金石"的 ARC-AGI-1 公共集上跑到 29.5% pass@2，每题推理成本只要 0.0007 美元——比 OpenAI 已经降价 80% 之后的 GPT 5.6 Luna（Low） 便宜约 11 倍，代价是精度低 4.7 个百分点。

它的关键做法是不再把思考"说出来"（chain-of-thought）——而是让模型在一个高维潜空间里迭代循环地"默想"，直接给出答案。

核心创新：为什么"少说话"反而更聪明

传统 Chain-of-Thought（说出来的思考）

  • 模型把每一步中间推理生成为文本 token
  • 再把这些 token 追加进上下文继续算
  • token 越多，成本、延迟越高，还会挤占上下文
  • 本质是把"思考"外化为"写作"

BDH-CQ 的 Recurrent Latent Reasoning（默想）

  • 输入示例进入模型后持续更新一段"循环记忆"
  • 在高维潜空间里迭代计算求解
  • 不生成中间文本，直接输出最终答案
  • 思考"原生"发生，不借道自然语言"打草稿"

整体推理流程（示意）

输入 few-shot 示例
循环记忆连续更新
潜空间内多轮迭代
读出答案
类比：人类做数学题时，绝大多数中间步骤只在脑内进行，不会每一步都说出来或写下来。CoT 相当于强制"念出来"，而 BDH-CQ 更接近"默算"。

先给最强反驳

  • 比较的公平性存疑。 BDH-CQ 用硬件实测成本，被比较对象是 API 报价。API 里含毛利、路由、安全税，把两者放同一横轴上"便宜 11 倍"容易夸大架构优势。
  • ARC-AGI-1 是否代表"通用推理"仍有争议。 它是 grid 变换类抽象题，训练分布匹配得好就能拿高分——2024 年起就有大量"专门刷 ARC"的做法。跨 benchmark 的可迁移性还没证。
  • 29.5% 并不是绝对高分。 排行榜上纯精度更高的系统很多；BDH-CQ 打的是"性价比 Pareto 前沿"，不是"精度 SOTA"。
  • 潜空间推理的可解释性更差。 CoT 至少能被人读、被审计；把推理藏进 latent state 后，安全与对齐团队要重新造工具去看它在想什么。
  • "扩展到 600B 仍保持潜推理能力"目前只是声明。 迄今公开的是 150M 结果，Scaling law 论证尚未开源验证。

为什么它重要（如果结论成立）

  • 把"推理成本"从架构上砍下来。 过去业界默认"更强推理 = 更多 token = 更贵"，本文用一个反例挑战了这条隐含定律。
  • 指向"后 Transformer"路线的一种具体形态。 Pathway 押注的 BDH 架构强调把记忆与推理"留在模型里"，而不是塞进不断扩张的上下文窗口。
  • 可能重塑端侧与实时场景的可行性边界。 150M 参数、亚毫美分级成本，意味着推理式 AI 有机会跑进工业控制、事件响应、终端设备。
  • 为"小模型 + 强推理"这条支线再添一个存在证明。 与今年上半年的 Penelope、DiscoLoop、Looped Transformers 等潜循环推理工作形成一片新研究群落。

术语速查

术语通俗解释
ARC-AGI-1François Chollet 提出的抽象推理基准。给几个"输入-输出网格"示例，让模型推出规则并预测新题的输出。人类平均正确率高，但对大模型一直是硬骨头。
pass@2允许模型出 2 个候选答案，只要其中一个对就算通过。对比 pass@1 更宽松，是 ARC 榜通用口径。
In-Context Learning不改权重、只靠 prompt 里的示例就学新任务的能力。
Latent Space（潜空间）模型内部的高维连续向量空间，每个方向不对应任何具体词，但承载"意思"。
Recurrent（循环）让同一层参数被多次调用，每一步的输出作为下一步的输入——类似 RNN 的思路。
Chain-of-Thought (CoT)让模型把推理过程"说出来"，逐步生成文字，再基于这些文字得出结论。
